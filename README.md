# Ressources VBWEB

Site de ressources et guides pour VBWEB, incluant :
- Guide SEO complet
- Services SEO
- Ressources et outils

## Technologies utilisées

- Next.js 13+
- React
- Tailwind CSS

## Installation

```bash
npm install
npm run dev
```

Le site sera accessible sur [http://localhost:3000](http://localhost:3000)

## Déploiement

Le site est déployé sur Vercel.
